# numerical_methods
lab2_1.py - Интерполяционный многочлен Лагранжа
Реализация построения интерполяционного полинома Лагранжа по заданным узлам.

lab2_2 - Схема Эйткена
Реализация схемы Эйткена (метод последовательного уточнения) для вычисления значений интерполяционного полинома.

lab2_3 - Многочлен Ньютона
Построение интерполяционного многочлена Ньютона с использованием разделенных (или конечных) разностей.

lab2_4.py - Метод наименьших квадратов
Аппроксимация таблично заданных функций с помощью метода наименьших квадратов (МНК).

lab2_5.py - Сплайны
Построение кубических сплайнов для интерполяции функций.

lab2_6.py - Формулы Ньютона и Гаусса
Использование интерполяционных формул Ньютона и Гаусса для равноотстоящих узлов.
